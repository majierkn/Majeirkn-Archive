# Comandos

Música: `/play`, `/search`, `/nowplaying`, `/stop`, `/leave`.

Fila: `/queue`, `/skip`, `/remove`, `/clear`, `/shuffle`, `/move`.

Controles: `/volume`, `/loop`, `/filter`.

Playlists: `/playlist criar`, `/playlist listar`.

Administração: `/setup`, `/stats`. Desenvolvimento: `!sync`, `!reload` (owner-only).
